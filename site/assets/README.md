# LinkSphere campaign artwork

Original campaign artwork generated for LinkSphere with `gpt-image-2`.

- `connected-devices-*.webp`: unbranded computers, a server and a phone connected by an AI sphere.
- `intelligence-*.webp`: a glass AI sphere surrounded by terminal, file and desktop symbols.

Responsive WebP variants are provided at 800 and 1536 pixels wide. These are conceptual promotional images, not screenshots of a live device session. They contain no third-party logos or device identities.

- `device-*.webp` and `glass-*.webp`: transparent objects generated from the campaign references, cropped into independent layers for scroll and pointer parallax. Static images remain as a fallback when layers cannot load.

- `file-flow-*.webp`: full-screen file transfer campaign scene.
- `connected-world-*.webp`: full-screen remote device connection campaign scene.
